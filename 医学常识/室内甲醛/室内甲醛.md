# 引言
甲醛是一种有机化合物，其结构是甲烷的一个氢换成羰基（`C=O`）形成一个醛基（`-CHO`），比较常见的作用是防腐，因此其35~40%的水溶液（福尔马林）常用来保存生物样本。近十几年来甲醛出现在普罗大众的视野中往往是作为一种普遍存在于家具中有毒物质的角色，这主要是因为大概在1950~1960年之间人造木板开始被用于住房建设后就一直被广泛应用，而2009年美国国家癌症研究所的研究发现频繁接触甲醛的化工厂工人死于血癌、淋巴癌的几率比接触甲醛机会较少的工人高很多。
> 最初的人造板材中比较有代表性的是粒子板，是通过将小木头、木屑等切削成一定规格的碎片，然后拌胶水、硬化剂等，在一定温度和压力下压制成的木板。这种木板成本低（相对于直接从一个木桩切割出特定的形状）、制备方法方便大工厂规模化应用，因此被广泛地生产使用。但是人造板材中使用的胶水，其生产原料中含有甲醛（因为这一类甲醛胶水成本低，因而使用广泛），胶水中部分未反应的甲醛就会在家具使用过程中释放。

但是甲醛作为一种常用的化工品，在建筑材料领域不仅仅出现在合成板材的胶水中，同样也可能存在于一些乳胶漆、地固墙固之中。作为一种对人体健康有严重危害，且在建材和家具中非常常见的物质，甲醛一直保持着较高的被关注度。  

# 分辨板材
- 实木板是采用完整木材制成的板材。也就是从一个木桩上切割出所需的形状，这显然是会浪费大量边角料，并且对于尺寸越大的实木板，需要的树桩越大，而大树木的生长周期长，因此显然实木板是一种成本非常高的板材。但也正因为简单纯粹，实木板是最为安全环保的选择。**识别实木板材区别于其他板材的特点是木纹连续，具有天然木材的芳香气味。一般从成品的截面还是比较容易区分的，还有一个重要的辅助因素就是价格。**
- 人造板材有很多种，比较基础的是[引言](#引言)中提到的粒子板（颗粒板），粒子板的这种制造方式自然导致了其板材的截面应该是能够看出组成板材的碎屑的，并且其制备过程用的胶水很多，因此其环保型完全取决于使用的胶水。

# 选购
按照环保等级标识购买。   
相关的国家强制性标准为**GB 185680-2025 室内装饰装修材料 人造板及其制品中甲醛释放限量**。  
该标准规定了人造板制品（人造板为主要材料加工而成的产品）的限量值为$\leq0.05 mg/m^3$，限量标识为$E_0$。  
而人造板的甲醛释放限量值为$\leq 0.124mg/m^3$，限量表示为$E_1$。  
标准中规定了甲醛释放量测定的方法，根据标准条件处理试件之后，将试件放在气候箱中释放甲醛，48h之后测量，测量的是气候箱中空气的甲醛质量浓度。  
作为强制性标准，企业生产质量控制中也要通过相应标准中的方法对试件在一定条件下释放的甲醛进行测试。  
***因此在购买的时候问清楚产品是否符合对应标准是最直接简单的方法。***   

根据甲醇的毒理性资料，其对于人体的亚急性和慢性毒性为：人吸入$20-70mg/m^3$的甲醛气体长时间，食欲丧失、体重减轻、无力、头痛、失眠；人吸入$12 mg/m^3$长期接触、嗜睡、无力、头痛、手指震颤、视力减退。  
工作场所空气中有毒物质的最高容许浓度为$0.5 mg/m^3$    
根据强制标准，符合$E_0$标准的人造板在气候箱中48h之后取样，测得空气中的甲醛浓度不超过$0.05 mg/m^3$，根据**GB/T 17657-2022 人造板及饰面人造板理化性能试验方法**中的规定的方法提到：气候箱法至少每小时换气一次，实际上在一定程度上模拟了室内空气流通的情况。也就是说室内如果存在大量的甲醛释放源，即使这些产品全都符合相应的标准，室内空气中的甲醛浓度仍然是可能超过$0.5 mg/m^3$的。并且根据**GB/T 18883-2022 室内空气质量标准，室内空气中甲醛浓度的限值为0.08 mg/m^3**。因此，还需要了解室内空气中甲醛的测试方法，才能保证居住环境的安全。  

# 普通人室内甲醛测试方法
由于室内环境甲醛浓度问题的普遍性，市场上出现了非常多的产品。  
甲醛检测相关标准有**GB/T 18204.2-2025 公共场所卫生检验方法 第2部分：化学性指标**，该标准规定了甲醛的多种测定方法。  
## 甲醛检测盒
标准中提到的酚试剂分光光度法利用甲醛与酚试剂反应生成嗪，嗪在酸性溶液中被高铁离子氧化形成蓝绿色化合物，进而着色深浅来判断甲醛含量。目前市面上主流的检测盒的比色卡都是蓝绿色，因此可以判断是采用的酚试剂方法。  
根据标准，当采气体积为10 L时，测量范围为$0.01-0.20 mg/m^3$  
这一类产品并没有相关的强制性质量标准，因此最好是使用同时购买多种进行交叉对比。  

## 甲醛检测仪
市面上另一类家用甲醛测量方法是便携式甲醛检测仪，一般除了检测甲醛，还可以测量其他多种TVOC（总挥发性有机物）气体浓度。  
在国标中提到了电化学传感器法：甲醛气体通过传感器，在电解质催化作用下，甲醛分子在电极上发生氧化还原反应而形成电子转移，在外电压作用下形成与甲醛质量浓度呈正比的电流。根据标准，这种方法测量甲醛的浓度范围为$0.2 mg/m^3-5 mg/m^3$，然而市面上的便携式甲醛检测仪显示屏显示下限有$0.001 mg/m^3$，甚至$0.0001 mg/m^3$，这可能是因为电化学方法近年来更新迭代较快的原因，在国家知识产权局的专利检索中找到一个于2026.05.19公开的专利**一种基于压电陶瓷驱动气流主动扩散的微型集成化电化学甲醛传感器及其制备方法**中，提到了通过压电陶瓷振动从而驱动气流扩散，提高了甲醛气体扩散到电极表面的速度，其实验数据的检测下限为$0.01 mg/m^3$。

# 室内环境甲醛去除方法
由装修材料和家具释放造成的甲醛污染往往是长期且缓慢的，最好就是使用完全不含甲醛的物品，从根源上消除甲醛的存在；其次是购买符合标准的，并且考虑空间中总的甲醛量，控制甲醛浓度低于$0.08 mg/m^3$的标准。
